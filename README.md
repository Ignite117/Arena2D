# Arena2D

Top-down 2D-арена на Unity: отбивайтесь арбалетом от волн врагов, которые преследуют вас со всех сторон. Уворачивайтесь перекатом, следите за выносливостью и набирайте как можно больше убийств, пока не кончится здоровье.

## Геймплей

- **Арена и волны врагов.** Враги появляются по кругу вокруг игрока и сразу бегут к нему. Одновременно на арене может находиться ограниченное число противников.
- **Арбалет.** Стрельба болтами в сторону курсора мыши. У арбалета есть перезарядка и кулдаун, а каждый выстрел тратит выносливость.
- **Перекат.** Быстрый рывок в направлении движения с короткими кадрами неуязвимости (i-frames). Тоже тратит выносливость.
- **Счёт.** HUD показывает текущее здоровье и количество убитых врагов.
- **Game Over.** При гибели игра ставится на паузу, появляется панель с возможностью перезапуска.

## Быстрый старт

### Требования

- [Unity Hub](https://unity.com/download)
- Unity **6000.2.5f1** (Unity 6). Другие версии могут открыть проект, но он собирался именно на этой.

### Запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Ignite117/Arena2D.git
   ```
2. В Unity Hub нажмите **Add → Add project from disk** и выберите папку `Arena2D`.
3. Откройте проект (при первом запуске Unity сам подтянет пакеты и создаст папку `Library`, это может занять несколько минут).
4. Откройте сцену `Assets/Scenes/Main.unity` и нажмите **Play**.

### Сборка

`File → Build Profiles` (или `Build Settings`) → выберите платформу → **Build**. В список сцен уже добавлены `Main` и `SampleScene`; игровой уровень находится в `Main`.

## Структура проекта

```
Arena2D/
├── Assets/
│   ├── Scenes/              # Main (основной уровень), SampleScene
│   ├── Scripts/             # Весь игровой код (см. ниже)
│   ├── Prefabs/             # Bolt, Enemy, Enemy Variant, Pillar
│   ├── Settings/            # Настройки URP 2D Renderer
│   ├── TextMesh Pro/        # Ресурсы TextMesh Pro для UI
│   ├── InputSystem_Actions.inputactions
│   └── *.png / *.jpg        # Спрайты и текстуры (пол, стены, трещины, сундук и т. д.)
├── Packages/                # Зависимости Unity (manifest.json)
└── ProjectSettings/         # Настройки проекта
```

### Скрипты

| Файл                    | Назначение                                                                                   |
|-------------------------|----------------------------------------------------------------------------------------------|
| `PlayerController2D.cs` | Движение, прицеливание на курсор, выносливость, перекат и кадры неуязвимости                 |
| `PlayerHealth.cs`       | Здоровье игрока, получение урона, смерть и вызов экрана Game Over                            |
| `Crossbow.cs`           | Стрельба болтами, кулдаун, перезарядка, расход выносливости                                  |
| `Bolt.cs`               | Снаряд: наносит урон врагу, уничтожается при попадании или столкновении со слоем `Obstacle`  |
| `Enemy.cs`              | Враг: преследует игрока, наносит контактный урон, считает убийства при гибели                |
| `Spawner.cs`            | Периодический спавн врагов по окружности вокруг игрока с лимитом одновременно живых          |
| `GameStats.cs`          | Статический счётчик убийств                                                                  |
| `HUDController.cs`      | Отображение здоровья и убийств через TextMeshPro                                             |
| `GameOverUI.cs`         | Панель Game Over, пауза и перезапуск сцены                                                   |

### Слои физики

В проекте используются слои `Player`, `Enemy`, `Obstacle` и `Projectile`. Болты уничтожаются при контакте со слоем `Obstacle`, поэтому препятствия и стены нужно помещать именно в него.

## Технологии

- Unity 6 (6000.2.5f1)
- Universal Render Pipeline (2D Renderer)
- Physics 2D
- TextMesh Pro / uGUI
- Input System и legacy Input Manager (режим *Both*)
- Cinemachine, 2D Tilemap, 2D Animation и другие 2D-пакеты из стандартного шаблона
